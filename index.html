Enigma
Remote Work Project

Introduction:

Welcome to my Digital Nomad VPN Setup — the modern “Enigma” machine.

This project is a reliable, always-on home VPN server built around a Raspberry Pi (located at one's home) paired with a GL.iNet travel router. It would allow an individual to work from anywhere in the world while maintaining a safe, domestic IP address.

Whether for work restrictions, accessing US-only services, banking security, or simply maintaining a consistent digital footprint, this setup routes all my traffic through a home connection. It’s clean, secure, fast, and provides independence without compromising on access or privacy.

  • Software
  • Configuration

Hardware

  • Ethernet Cable (for stable connection)
  • GL.iNet Router(s) — 2x recommended (1 home server + 1 travel client)
  • M.2 HAT+
  • NVMe SSD
  • Raspberry Pi (Pi 4 or Pi 5, 4GB+ recommended)
  • Raspberry Pi Enclosure (with good cooling)
  • Reliable Power Supply (official or high-quality 5V/3A+)
  • Uninterruptible Power Supply (UPS)

Software

  • Fail2Ban (security)
  • Pi-hole (ad-blocking + local DNS)
  • PiVPN (WireGuard)
  • Raspberry Pi OS (64-bit Lite)
  • Unbound (secure recursive DNS)
  • WireGuard Tools & qrencode (for QR code configs)

Network & Configuration

  • Dynamic DNS (DuckDNS, No-IP, or custom domain)
  • Port Forwarding (UDP 51820 or custom port)
  • Static Local IP for Raspberry Pi
  • UPnP (optional, if supported by your router)

Client Side (Uruguay)

  • GL.iNet Travel Router (as WireGuard client — recommended)
  • WireGuard App (on laptop, phone, tablet as backup)
  • USB-C Ethernet Adapter (for laptop if needed)

Backup & Monitoring

  • Tailscale or ZeroTier (backup VPN — highly recommended)
  • Uptime Monitoring (UptimeRobot or similar)
  • Multiple Client Configs (stored securely)
  • Documentation (save all keys, DDNS, ports, etc.)

Preparation & Testing

  • Assemble and boot Raspberry Pi with NVMe SSD
  • Configure static local IP address for the Pi
  • Install Raspberry Pi OS and run updates
  • Install and configure PiVPN (WireGuard server)
  • Set up Dynamic DNS (DuckDNS / No-IP / etc.)
  • Configure port forwarding on home router (UDP 51820 or custom)
  • Install Pi-hole + Unbound + Fail2Ban
  • Generate and test multiple WireGuard client configs
  • Set up GL.iNet travel router as WireGuard client
  • Test full VPN connection from external networks (coffee shop, mobile hotspot, friend’s house)
  • Test connection stability and speed (upload from TN should be solid)
  • Test failover with Tailscale / ZeroTier
  • Verify local network access (if needed: NAS, printers, etc.)
  • Create full documentation (configs, passwords, DDNS, recovery steps)
  • Simulate power outage / reboot and verify auto-reconnect
  • Pack checklist: Travel router, power supplies, Ethernet cables, SSD backup
  • Final test run 24–48 hours before departure
